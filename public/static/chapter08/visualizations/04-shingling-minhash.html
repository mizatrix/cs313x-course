Shingling & Near-Duplicate Detection

Web crawlers fetch many near-identical pages. Convert each document into a set of k-word shingles, then measure overlap with Jaccard similarity.

MinHash Estimate

For each hash function, the minimum hash over a document's shingles is its signature. The fraction of signatures that match across A and B is an unbiased estimate of the Jaccard similarity.

Pr[minhash match] = J
Why It Matters

A crawler that indexes duplicate pages wastes storage and floods results. Comparing full documents is O(n²); MinHash + LSH lets the indexer detect near-duplicates in near-linear time.
