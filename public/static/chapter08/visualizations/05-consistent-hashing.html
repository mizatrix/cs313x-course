Consistent Hashing Ring

Keys (crawled URLs) are hashed onto a ring and assigned to the next node clockwise. Add or remove a node and watch how few keys move — unlike hash mod N, which remaps almost everything.

💡
Try This: Add a node and note "keys moved." Only keys in the new node's arc relocate — about K/N of them — while hash mod N would shuffle nearly all K keys.

Why It Matters

A web crawler shards URLs across many servers. With consistent hashing, adding or losing a machine only re-shuffles ~K/N keys, so caches and crawl frontiers stay mostly warm. With hash mod N, changing N rewrites nearly every assignment.
