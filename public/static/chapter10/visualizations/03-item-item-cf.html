Why item-item?

Item–item similarities are computed from columns, which change slowly: a catalog has far fewer items than users, and an item's rating profile is stable. So the item–item matrix can be precomputed offline and reused for everyone — far more scalable than recomputing volatile user–user neighborhoods at request time. Predictions also use the active user's own ratings, so they update instantly without re-finding neighbors.
