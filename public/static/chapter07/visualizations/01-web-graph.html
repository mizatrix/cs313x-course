Web Graph & Random Surfer

The web is a directed graph: pages are nodes, links are arrows. A "random surfer" follows links — and occasionally teleports — building up visit counts that approximate PageRank.

💡
Try This: Press Auto-walk and watch the visit bars. Which page gets the most visits? Notice it is usually the one with many high-quality in-links, not the one that links out the most.

Why links are votes

Each link is a vote for the page it points to. A page is important if many pages link to it (in-links) — and even more so if those linking pages are themselves important. The surfer's long-run visit share converges to exactly this idea: PageRank.
