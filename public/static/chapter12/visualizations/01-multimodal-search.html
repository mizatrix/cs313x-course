Multimodal Search

Text and images live in one shared embedding space. A CLIP-style model lets a text query retrieve images by cosine similarity — no captions or keywords needed.

💡
Try This: Type "a fluffy pet" or pick a query pill. Watch the violet query dot land in the shared space and the nearest image icons light up green — that is cross-modal retrieval.
Shared Embedding Space

🟣 = your text query · 🖼️ icons = image items. Both modalities are projected into the same 2D space. Nearby = semantically similar. Green rings mark the top matches.

Key Insight

Because text and images share one joint space, the same cosine-similarity ranking works across modalities — a text vector retrieves image vectors directly. This is how CLIP-style models power image search from words.
