Federated Learning & Privacy

Devices train on their own private data and send only model updates to a server, which averages them into a shared global model — raw data never leaves the device.

Trade-offs

Privacy: raw data stays on-device — only small weight updates move. Communication cost: every round uploads/downloads model weights repeatedly. Non-IID data: when devices see very different data, averaged updates conflict and convergence slows.
