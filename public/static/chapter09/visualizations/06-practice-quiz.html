Quick Reference
cos(q, d) = (q · d) / (‖q‖ · ‖d‖)

Bi-encoder encodes query and document separately → embeddings can be pre-computed and indexed for fast retrieval.
Cross-encoder processes the query–document pair jointly → far more accurate but too slow to score the whole corpus, so it is used to re-rank a shortlist.
