Key Insight

Exact search is O(N) — it compares the query to every vector. ANN partitions the space into buckets / clusters and only scans the bucket the query falls into (plus neighbours). That makes it fast and scalable, but a true neighbour sitting just across a cell boundary can be missed — the classic recall vs. latency trade-off.
